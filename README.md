### A little about me

I'm **Mohammad Aqib**, a **Full Stack Developer** interested in building useful applications and connecting them with APIs and AI.

My current featured project is **Codex-open-dot**, a customized personal AI agent app for macOS based on Composio Community's Open Dot. My edition brings together custom model providers, durable tasks, approval controls, searchable knowledge and reusable workflows.
